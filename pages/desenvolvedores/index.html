Sobre o projeto

Como o atlas foi feito.

O conteúdo parte de literatura científica e de referências bibliográficas reais, listadas na página de Fontes. As ilustrações são vetoriais, desenhadas para o projeto, e as fotografias vêm do Wikimedia Commons com os créditos de autoria preservados.

O site é estático — HTML, CSS e JavaScript, sem dependências de build —, o que o mantém leve e permite abri-lo em qualquer navegador, inclusive no celular.
