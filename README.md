# ABYSSAL — projeto organizado para VS Code

A aparência e as funcionalidades do site foram preservadas, mas o código foi separado em arquivos menores para facilitar edição.

## Edite aqui

- `index.html` — estrutura da página e pontos principais do documento.
- `css/styles.css` — cores, tipografia, layout, responsividade e animações.
- `js/theme.js` — inicialização do tema.
- `js/data.js` — banco de espécies, zonas, ecossistemas, regiões e dados.
- `js/core.js` — funções centrais e navegação.
- `js/visual.js` — ilustrações e lógica visual.
- `js/journal.js` — Diário de Bordo, modos, tema e descoberta do dia.
- `js/home.js` — Home.
- `js/ocean.js` — página O Oceano.
- `js/content-pages.js` — zonas, ecologia, ecossistemas, catálogo e filtros de espécies.
- `js/deep-pages.js` — páginas de espécies, profundezas, conservação, exploração, recifes, glossário e demais páginas de conteúdo.
- `js/game.js` — ROV, sonar, missões, controles e tela cheia.
- `js/app.js` — busca global, menu, roteamento e inicialização.

## Exemplos

**Adicionar uma espécie:** edite `js/data.js`.

**Mudar o visual:** edite `css/styles.css`.

**Mudar a Home:** edite `js/home.js`.

**Mudar “O Oceano”:** edite `js/ocean.js`.

**Mudar o jogo:** edite `js/game.js`.

**Mudar o Diário:** edite `js/journal.js`.

## Como rodar

Abra esta pasta no VS Code. Instale a extensão `Live Server`, clique com o botão direito em `index.html` e escolha `Open with Live Server`.
