## Fotografias reais

As áreas de imagem agora usam um catálogo estático de fotografias reais do Wikimedia Commons, sem chamadas à API para descobrir a imagem em tempo de execução. O navegador ainda precisa de internet para acessar as fotografias externas. O enquadramento é centralizado no CSS e os equipamentos preservam mais da imagem com `contain`.
